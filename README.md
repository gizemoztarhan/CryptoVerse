## 💰 Cryptoverse

Cryptoverse is a sleek, responsive web interface focused on the world of cryptocurrencies.
Built with HTML, CSS, and Bootstrap, it’s designed to provide a seamless experience across all screen sizes.

---

## 🚀 Features
- Clean and modern user interface

- Fully responsive design

- Built using Bootstrap for fast and flexible development

- Smooth and responsive hover animations to improve user interaction

- Mobile-Friendly Navigation with Bootstrap

---

## 🛠️ Technologies Used
- HTML5

- CSS3

- Bootstrap 5
